# Task 3 – Interactive Sales Dashboard

## Project Overview

This project is an interactive sales dashboard created as part of the Skillzeno internship Task 3.

The dashboard analyzes Supermart Grocery Sales data and provides an easy-to-understand view of sales, profit, orders, categories, regions, and top-performing cities.

## Dataset

Dataset used:

Supermart Grocery Sales - Retail Analytics Dataset

The dataset contains retail sales information including:

- Order ID
- Category
- Region
- City
- Sales
- Profit
- Other sales-related information

## Dashboard Features

The dashboard includes:

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Sales KPI
- Category Filter
- Region Filter
- Sales by Category
- Profit by Category
- Sales by Region
- Top Cities by Sales
- Dynamic Insights

## Interactivity

Users can select a Category and Region from the filters.

The KPI values, charts, and insights update automatically according to the selected filters.

## Key Insights

The dashboard helps identify:

- Overall sales performance
- Overall profit performance
- Category-wise sales and profit
- Region-wise sales
- Top-performing cities
- Changes in performance based on selected filters

## Conclusion

This interactive dashboard provides a simple and user-friendly way to analyze supermarket sales data and understand important business insights.
