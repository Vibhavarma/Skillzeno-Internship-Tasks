# Task 4 – Business Analytics Report

## Project Overview

This project was created as part of the Skillzeno Internship – Task 4.

The objective of this project is to analyze supermarket sales data, identify important business patterns, and provide data-backed recommendations.

## Business Problem

The analysis focuses on understanding:

- Overall sales and profit performance
- Category-wise performance
- Region-wise performance
- City-wise sales performance
- Areas that require further attention
- Business opportunities based on the available data

## Dataset

The project uses the Supermart Grocery Sales dataset.

The dataset contains retail information related to:

- Orders
- Categories
- Regions
- Cities
- Sales
- Profit

## Key Analysis

The report includes:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Category
- Profit by Category
- Sales by Region
- Top Cities by Sales
- Key Business Insights
- Data-Backed Recommendations

## Technologies Used

- Python
- CSV
- HTML
- CSS

## Project Files

- `Task_4_skillzeno.py` – Python analysis and report generation script
- `Supermart Grocery Sales - Retail Analytics Dataset.csv` – Dataset
- `business_analytics_report.html` – Final business analytics report
- `vReadme.md` – Project documentation

## Business Insights

The analysis identifies high-performing categories, regions and cities and highlights areas that can be reviewed for further improvement.

The report also considers both sales and profitability rather than looking at sales alone.

## Recommendations

Based on the analysis, recommendations are provided for:

- Focusing on high-performing categories
- Strengthening strong regional markets
- Reviewing low-performing categories
- Comparing city-level performance
- Monitoring profitability along with sales

## Conclusion

This project demonstrates how sales data can be analyzed to identify business patterns and generate practical, data-backed recommendations.
